# LÉLU — VoxCPM2 voice sidecar

Her own voice, generated by the real **OpenBMB VoxCPM2** model
(`openbmb/VoxCPM2`, <https://github.com/OpenBMB/VoxCPM>) from the reference
recording committed in this repository:

    public/audio/voice/lelu-voice-reference.m4a   (48.81 s, AAC, committed at 62ad310)

No paid cloning API is involved. ElevenLabs remains the fallback path that
already exists in `src/core/voice/elevenLabsTts.ts`.

## Why a separate process

LÉLU is Vite/Bun; VoxCPM2 is PyTorch. They cannot share a process, so
`server.py` is the HTTP boundary. The browser never reaches it:
`plugins/voiceApi.ts` talks to it server-side.

## Files

| File | What it is |
| --- | --- |
| `server.py` | The sidecar. `GET /health`, `GET /v1/models`, `POST /warmup`, `POST /v1/audio/speech` (OpenAI-compatible). Lazy model load, one generation at a time, bounded queue (503 past it), LRU cache by text, WAV or chunked PCM. `/health` reports device, sample rate, reference hash, load time, last latency and RTF. |
| `bootstrap.py` | Resumable weight acquisition. Disk check → `snapshot_download` (resumes from HF cache) → per-file size verification → atomic `.voxcpm/state/model-ready.json`. `--check` answers "do we already have the weights?" with no network. |
| `selfcheck.py` | The acceptance test: verify weights → load model → generate three sentences from the reference clip → measure each WAV (duration, RMS, peak, median F0, spectral centroid) → write evidence + a listenable MP3. |
| `install.sh` | Reproducible env. Detects GPU, installs exactly one matching torch/torchaudio pair (never a CPU torch beside a CUDA torchaudio — that failure is `OSError: libcudart.so.13`), then pins `requirements.txt` and writes `requirements.lock`. |
| `requirements.txt` | Pinned non-torch deps (`voxcpm==2.0.3`, numpy, soundfile, imageio-ffmpeg, huggingface-hub). |

`src/core/voice/gpuWorkers.ts` is the compute pool: it parses workers
(Kaggle / Colab / ZeroGPU / Lightning / tunnel / local), probes `/health`,
picks the best awake worker, fails over, and remembers failures for a
cooldown so a dead session is not retried on every sentence. It never
returns a token, and a sleeping worker is reported unavailable rather than
silently replaced by a different speaker.

## Run it

```bash
bash services/voxcpm/install.sh            # once per machine (GPU auto-detected)
.venv-voxcpm/bin/python services/voxcpm/bootstrap.py --check   # are weights here?
.venv-voxcpm/bin/python services/voxcpm/bootstrap.py           # resume/get them
.venv-voxcpm/bin/python services/voxcpm/server.py --port 8788 --warmup
.venv-voxcpm/bin/python services/voxcpm/selfcheck.py           # does she speak?
```

Smoke test:

```bash
curl -s localhost:8788/health | jq '{loaded, device, sampleRate, reference}'
curl -s -X POST localhost:8788/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"input":"Hello. I am Lélu.","response_format":"wav"}' -o /tmp/lelu.wav
```

## Environment

| Variable | Default | Meaning |
| --- | --- | --- |
| `VOXCPM_MODEL_ID` | `openbmb/VoxCPM2` | model repo |
| `VOXCPM_DEVICE` | `auto` | `cpu`, `cuda`, `mps` |
| `VOXCPM_HOST` / `VOXCPM_PORT` | `127.0.0.1` / `8788` | bind address |
| `VOXCPM_REFERENCE_AUDIO` | the repo clip | cloning source |
| `VOXCPM_REFERENCE_SECONDS` | `12` | seconds of it used as conditioning |
| `VOXCPM_CFG_VALUE` | `2.0` | guidance scale |
| `VOXCPM_TIMESTEPS` | `10` | diffusion steps (lower = faster) |
| `VOXCPM_MAX_CHARS` | `900` | one segment |
| `VOXCPM_MAX_QUEUE` | `4` | waiting requests before 503 |
| `VOXCPM_CACHE_ENTRIES` | `48` | identical-text LRU |
| `VOXCPM_TOKEN` | empty | bearer token; **required for any public tunnel** |
| `VOXCPM_WARMUP` | `1` | load weights at start |

App side: `VOXCPM_WORKERS` (JSON array of `{id, kind, url, token}`),
`VOXCPM_BASE_URL` + `VOXCPM_TOKEN` for one worker, `VOICE_PROVIDER`
(`voxcpm` | `elevenlabs` | `auto`).

## Limits, stated plainly

- **CPU inference is not real-time.** Whatever RTF `selfcheck.py` prints is the
  truth; expect a reply to take longer than it plays.
- **Free GPU hosting is temporary.** Kaggle and Colab end sessions; ZeroGPU has
  quotas; Lightning's free allowance is limited. A worker disappearing is normal
  and is what the pool's failover and ElevenLabs fallback exist for. Nothing here
  provides permanent hosting.
- **Audio audibility is unverifiable on this VM** (no output device): generation
  is verified by bytes and measurements, playback by the existing client path.
- **Acoustic numbers are not speaker verification** — no embedding model is used.
