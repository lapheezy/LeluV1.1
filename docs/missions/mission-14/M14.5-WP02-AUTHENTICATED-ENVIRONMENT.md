## 3. Why the key is required

A publishable key is the project's client identifier; without it Supabase answers 401 before Auth, PostgREST or RLS is reached. A signed-out client, a fixture or the production key cannot substitute for it.

The supplied address has no matching application Auth user according to the owner's read-only lookup. The code does not insert into `auth.users`. It calls the normal `signInWithOtp` path with `shouldCreateUser: true`; the project's existing Auth settings decide whether that creates a user. If email sign-up is disabled, the UI reports that instead of bypassing it.
