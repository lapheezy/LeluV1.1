## 5. Regression notes

- The Mission 14.3 offline harness still blocks all non-local hosts and records `supabaseAttempts: []`.
- The Mission 14.3 dispatcher harness still creates the project, writes/reads the sandbox, waits for Cosmos approval, records the graph, refuses `project.apply`, and reloads persisted state.
- The old blind Supabase subscriptions for projects, conversations and knowledge were removed from `attachRuntime()`; the continuity engine now owns those paths.
- Realtime project snapshot merging was removed because it could reintroduce an unconditional newer-timestamp overwrite beside the conditional path.
- `KnowledgeGraph` now applies a reconciled envelope to live instances, not only to storage.
- `MESSAGE_TEXT_LIMIT` remains declared in `SupabasePersistence` and is shared by the continuity transport; existing schema test passes.

---

## 6. Known limitations

1. Same-millisecond `updated_at` values cannot distinguish two writes; the existing schema has no separate revision column.
2. Documents (graph, spatial objects, Cosmos rooms) are conditional at row level; a conflict on one record blocks the whole document upload until resolved.
3. The multi-device result is a multi-context simulation, not two physical devices.
4. Neural Map has no persistent index to reconcile; it is derived.
5. Real cloud round trip, reconnect, conflict and multi-device acceptance remain blocked.
