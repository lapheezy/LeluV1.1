## 2. Pointer event-routing findings (measured)

The trace (`scripts/trace-cosmos-layers.mjs`) and pointer logs showed:

* A press aimed at the world is delivered to a **DIV**, sometimes a full-surface
  **BUTTON**, never to our `<canvas>` — the Cosmos draws its own interactive
  surface above the scene canvas. A canvas-target guard therefore rejected
  **every** real tap; the previous "selection" was only the build's own
  selection, never a click.
* The scene's canvases are stacked; the canvas carrying `data-lelu-creative`
  sits below the HUD/atmosphere canvas.
* The creative dock is HTML in the interface tree, outside the scene container.

## 3. Geometry-selection root cause

Three separate defects, all measured:

1. **Stale world matrices.** The Cosmos paints on demand; between frames
   `camera.matrixWorld` (and the root group's) can be a frame or more old, so a
   ray built from them lands behind the drawn object and misses. Fixed by
   updating both matrices before `setFromCamera`.
2. **Ineligible hits.** The raycaster does not skip invisible subtrees, so an
   archived or hidden object could be selected. Hits are now filtered against
   the canonical store's `visible` / `archived` state.
3. **Projection aimed at the origin.** The acceptance probe projected the
   object's origin; a chair's origin is the floor *between its legs*, so the
   point was empty space and so was the ray. The probe now projects the real
   bounding-box centre, and — more importantly — a person taps the mesh, which
   is what the ray tests.

No chair-specific coordinate, offset or name appears anywhere in the fix.

## 4. Final interaction architecture

```
press (window capture)
  └─ inside [data-lelu-scene-root]?           no → ignore (interface sheets, chat, menus)
  └─ inside a control? (button/a/input/field/
     dock/[data-lelu-no-creative-pick])        yes → ignore (native behaviour untouched)
  └─ raycast the REAL part meshes
       ├─ camera.updateMatrixWorld()
       ├─ root.updateWorldMatrix()
       ├─ nearest hit with a creativeId whose object is visible & not archived
       └─ miss → clear selection
  └─ hit → select canonical id (+ component)
       └─ tool ≠ select → begin gesture mutex, stopPropagation, start drag
drag (window pointermove/up)
  └─ move/rotate/scale in scene units around the pointer
  └─ release → store.setTransform()  (the canonical, persisted authority)
  └─ end gesture mutex → camera may orbit again
```

The scene root is resolved once from the canvas's own ancestor chain and marked
`data-lelu-scene-root` (visible in the DOM for diagnostics, removed on unmount).
There is no global hijack: anything outside that container never reaches the
handler, and every control inside it is excluded by the same `.closest()` test.

**Focus** was rebuilt as a request, not a calculation in the dock:
`requestCreativeFocus(id)` → the layer (which owns the meshes and camera)
computes the bounding box and calls the **same** camera bus. The dock used to
aim at the origin from 0.5 m, which framed the floor beneath a chair.

## 7. Canonical-store evidence

Every commit goes through `CreativeObjects.setTransform`, the single transform
authority, which persists to browser storage. The reload step asserts the
restored position is byte-identical to the committed one, so the drag updates
the real object rather than a visual clone.

## 9. Known limitations

1. **Physical device:** untested. Every "mobile" result is browser emulation.
2. **Overlapping objects:** nearest-hit-wins is implemented but not exercised;
   the dock cannot create two creations of the same kind side by side.
3. **Second furniture category:** no builder exists to test.
4. **Gown drag reliability:** the gown is a thin cloth surface; pressing the
   bounding-box centre can pass through an opening. Selection at the fabric
   works; a click test that aims only at the centre is flaky for textiles.
5. **Framing is tight:** a framed object can touch the frame edge (see
   `d-chair-01-selected.png`), because the distance is `max(0.85 m, 2.6 ×
   radius)`.
6. **LÉLU autonomy:** still **BLOCKED** — no reachable model provider in this
   environment (`scripts/verify-agentic.ts`: all 9 providers
   `missing-credentials-or-provider-cooldown`). Nothing here is LÉLU's own work.
7. Rotation and scale modes share the drag path but were not separately
   asserted with pointer evidence in this work package.
