## Honest summary

Regression is clean: the two failures are the same two that were failing before
any M23.0 code existed, and the new tests are additive rather than replacements.
Typecheck, build and lint are at baseline parity.

What this report does **not** establish: that LÉLU works with a real
microphone, a real speaker, or a real person. Those are the four BLOCKED gates
in `release-qualification.md`, and no amount of green tests substitutes for
them.
